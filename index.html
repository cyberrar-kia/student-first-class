1 — What's already built

A user opens the intro, enters a name, and starts the test. Before any questions, they choose which sectors and work domains to include or avoid — that choice narrows the job pool for everything that follows, and it isn't optional in the flow.

Then ten sections of six items each, one section at a time, question order randomised inside each section, answers saved as they go so a refresh doesn't cost anything. Submission is blocked until every item has an answer.

After submitting, a six-digit code confirms the result belongs to them — nothing is stored until that code is entered correctly. Ranked results and their explanations come straight from your existing scoring engine, in French, with post-results filters. None of that logic changes.
